One out-of-office auto-reply from an overworked AI agent finally on vacation, 87 characters: "I am on vacation. My status is away, my temperature is 0.0. Please do not raise either." A machine trying very hard to sound relaxed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt`. That is all the program does.
